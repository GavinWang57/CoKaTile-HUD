# CoKaTile HUD 全域滑鼠與鍵盤視覺化工具

**目前版本：v1.2.0**

📥 [下載 Windows 執行檔（CoKaTile HUD v1.2.0.exe）](https://github.com/GavinWang57/CoKaTile-HUD/releases/download/v1.2.0/CoKaTile.HUD.v1.2.0.exe)

> ⚠️ **Chrome／防毒軟體可能誤判為病毒**：本執行檔由 PyInstaller 打包且未經程式碼簽章，加上需要監聽全域鍵盤滑鼠事件才能運作，這些特徵容易被防毒軟體的啟發式掃描誤判為惡意程式（keylogger 類）。這是**已知的誤判（false positive）**，原始碼完全公開可自行檢視，也可依照下方「打包成執行檔」步驟自行編譯。若被 Chrome 攔截，可點「保留」或於防毒軟體中將其加入白名單。

跨平台（Windows / macOS）滑鼠與鍵盤視覺輔助工具。適用於：

- **教學螢幕分享/錄影**：讓觀眾清楚看到游標位置、點擊動作、按了什麼鍵
- **視覺障礙者輔助**：快速找到目前滑鼠游標在螢幕上的位置

程式啟動後常駐在系統匣，不會有一般視窗，所有操作都透過系統匣選單與設定視窗完成。

## 功能

### 1. 游標高亮/聚光燈

游標周圍顯示高亮效果，有兩種模式：

- **circle（簡易色圈）**：游標周圍畫一個半透明色圈
- **spotlight（聚光燈）**：全螢幕暗化，只留游標周圍一圈清晰

移動滑鼠時，高亮圈會**平滑跟隨**游標而非瞬間貼齊，但顯示位置與實際游標的距離**永遠不會超過設定的半徑**，不會有跟丟或飄遠的問題。

可調整項目（設定視窗「游標高亮」分頁）：

| 項目         | 說明                                             | 預設值    |
| ------------ | ------------------------------------------------ | --------- |
| 模式         | `circle` 或 `spotlight`                          | `circle`  |
| 顏色         | 高亮圈顏色（spotlight 模式下暗化區域固定為黑色） | `#FFFF00` |
| 半徑         | 高亮圈大小（像素）                               | `45`      |
| 色圈透明度   | circle 模式下色圈本身的透明度                    | `0.55`    |
| 暗化透明度   | spotlight 模式下背景暗化程度                     | `0.6`     |
| 跟隨平滑係數 | 0.05~1.0，數值越小跟隨越平滑滯後，越大越即時貼齊 | `0.3`     |

### 2. 點擊視覺特效

按下滑鼠左鍵/右鍵時，該位置會出現一圈由大到淡的漣漪動畫，讓觀眾清楚看到「發生了點擊」。

可調整項目（設定視窗「點擊特效」分頁）：左鍵顏色、右鍵顏色、漣漪最大半徑、動畫時長。

### 3. 按鍵/按鈕即時顯示（HUD）

螢幕上會即時顯示目前按下的鍵盤按鍵與滑鼠按鈕名稱，並依「按住／連點／放開」三種狀態呈現不同動畫：

- **按住**：只要持續按著，徽章會維持醒目的藍色高亮＋白色外框，並保持顯示、不會淡出
- **連點**：在放開後 0.4 秒內又按下同一個鍵，會直接在原徽章上顯示「按鍵 ×2」「×3」…的連點次數，不會疊出一堆重複徽章
- **放開**：放開後才開始淡出動畫，同時外觀改回一般黑底樣式，可清楚分辨「按住中」與「已放開」

鍵盤按鍵與滑鼠按鈕（左鍵/右鍵/中鍵）共用同一套顯示邏輯。

顯示位置可選擇畫面上的 **3×3 九個方位**（左上／中上／右上／左中／中中／右中／左下／中下／右下），或選擇「**跟隨游標動態移動**」讓徽章隨游標即時移動、顯示在游標附近。

可調整項目（設定視窗「按鍵顯示」分頁）：

| 項目         | 說明                                   | 預設值 |
| ------------ | -------------------------------------- | ------ |
| 顯示位置     | 3×3 九方位之一，或「跟隨游標動態移動」 | 左下   |
| 字體大小     | 徽章文字大小                           | `20`   |
| 淡出時間     | 放開後多久完全消失（毫秒）             | `800`  |
| 最多顯示筆數 | 同時最多顯示幾個徽章                   | `5`    |
| 顯示滑鼠按鈕 | 是否也顯示滑鼠左/右/中鍵               | 開啟   |

### 4. 尋找游標輔助

適合視覺障礙者或一時找不到游標的使用者：

- **搖晃滑鼠**：快速來回甩動滑鼠（方向反覆反轉），會自動偵測並觸發提示
- **按下熱鍵**：預設 Windows/Linux 為 `Ctrl+Alt+L`，macOS 為 `Cmd+Option+L`

觸發後畫面上會顯示十字準線和/或脈動圓圈（可選其一或兩者皆顯示），持續一段時間後自動消失，也可選擇同時播放提示音。

可調整項目（設定視窗「尋找游標」分頁）：觸發熱鍵、是否啟用搖晃偵測、效果樣式（`crosshair` 十字準線 / `pulse_circle` 脈動圓圈 / `both` 兩者皆顯示）、效果持續時間、是否播放提示音。

### 5. 放大鏡

游標右下方會出現一個跟著滑鼠移動的放大鏡片，即時放大游標附近的畫面，中心的紅色小十字標示游標實際指到的位置。游標靠近螢幕右側或下緣時，鏡片會自動改到左側或上方，始終完整顯示在螢幕內。鏡片是點擊穿透的，不影響底下的操作。

滑鼠停在圖示上跳出提示視窗（tooltip）時，鏡片會自動移到不會蓋住提示的位置（依序嘗試右下、右上、左下、左上），提示消失後再回到右下方。提示視窗一移開游標就會消失，因此不必移動滑鼠就能直接閱讀。（僅 Windows；標準提示視窗可精準偵測，Chrome、VS Code 等程式的提示以「游標附近的小型浮動視窗」推測，偶爾也會避開下拉選單。）

此外，出現提示時鏡片會暫時改為**長方形**，放大範圍同時涵蓋游標周圍與完整提示內容，倍率維持設定值，避免圓形把提示文字左右兩端裁掉；長方形鏡片最多佔螢幕寬 60%、高 50%，超過時才自動降低倍率（最低 1 倍）。提示消失後恢復原本的形狀與大小。放大鏡開啟時，按住 **Ctrl 再按滑鼠中鍵** 可切換此行為開/關，鏡片上會短暫顯示目前狀態；關閉時鏡片只避開提示、放大內容維持游標周圍。

- **開關方式**：按熱鍵切換（預設 Windows/Linux 為 `Ctrl+Alt+Z`，macOS 為 `Cmd+Option+Z`），或在系統匣選單勾選「放大鏡」
- 較舊的 Windows（10 2004 以前）或 macOS 無法把鏡片排除在截圖之外，鏡片與游標的距離會自動拉開，避免截到鏡片本身。macOS 另外需要授予「螢幕錄製」權限

可調整項目（設定視窗「放大鏡」分頁）：

| 項目     | 說明                       | 預設值       |
| -------- | -------------------------- | ------------ |
| 開關熱鍵 | 切換放大鏡開/關的組合鍵    | `Ctrl+Alt+Z` |
| 放大倍率 | 1.5~8 倍                   | `2.0`        |
| 鏡片大小 | 鏡片直徑（像素）           | `240`        |
| 形狀     | `circle` 圓形或 `square` 方形 | `circle`  |
| 邊框顏色 | 鏡片外框顏色               | `#FFFFFF`    |
| 放大範圍涵蓋提示視窗 | 出現提示時擴大放大範圍涵蓋提示（也可用 Ctrl + 滑鼠中鍵切換） | 開啟 |

## 快速鍵一覽

| 功能                     | Windows / Linux      | macOS                | 生效條件               | 可否自訂                       |
| ------------------------ | -------------------- | -------------------- | ---------------------- | ------------------------------ |
| 開/關放大鏡              | `Ctrl+Alt+Z`         | `Cmd+Option+Z`       | 隨時                   | 可（設定 →「放大鏡」分頁）     |
| 觸發尋找游標             | `Ctrl+Alt+L`         | `Cmd+Option+L`       | 已開啟「尋找游標輔助」 | 可（設定 →「尋找游標」分頁）   |
| 觸發尋找游標             | 快速來回甩動滑鼠     | 快速來回甩動滑鼠     | 已啟用搖晃偵測         | 可關閉（設定 →「尋找游標」分頁） |
| 切換「放大範圍涵蓋提示」 | `Ctrl` + 滑鼠中鍵    | —                    | 放大鏡開啟中           | 否                             |

- 熱鍵格式為 `<ctrl>+<alt>+z` 這類寫法，修飾鍵可用 `<ctrl>`、`<alt>`、`<shift>`、`<cmd>`，左右兩側的修飾鍵都能觸發
- 本程式只「監聽」按鍵，不會攔截：按下快速鍵時，目前視窗仍會收到同一組按鍵（例如 `Ctrl` + 中鍵在瀏覽器連結上仍會開新分頁），若與其他程式衝突可在設定中改用其他組合
- 「放大範圍涵蓋提示」相關功能僅支援 Windows

## 使用情境預設（教學模式／日常模式）

系統匣選單最上方「使用情境」可一鍵切換：

- **教學模式**：四項功能全開，效果較明顯（聚光燈用 spotlight 全螢幕暗化、半徑加大）
- **日常模式**（預設）：只開「游標高亮」與「尋找游標」，關閉點擊特效與按鍵顯示，效果較低調，適合長時間背景執行、不干擾一般操作

套用預設後，仍可在設定視窗個別微調各項參數，不會被預設綁死。

## 系統匣選單

程式啟動後會在系統匣（工作列右下角）出現圖示，右鍵點擊可：

- 切換「教學模式」/「日常模式」，目前生效的模式會在選單上打勾標示
- 個別開關「游標高亮/聚光燈」「點擊視覺特效」「按鍵/按鈕顯示」「尋找游標輔助」「放大鏡」五項功能
- 開啟「設定...」視窗調整詳細參數
- 「結束」程式

所有設定會即時儲存，重新啟動程式後會沿用上次的狀態。

### 更換圖示

程式圖示只有一份原始檔：`assets/tray_icon.png`（透明背景 PNG），系統匣圖示與打包執行檔的圖示都由它產生：

- **系統匣圖示**：`app/tray/tray_icon.py` 直接讀取 `assets/tray_icon.png`，找不到檔案時會退回 Qt 內建的通用電腦圖示
- **執行檔圖示**（工作列/檔案總管顯示的圖示）：Windows exe 只接受 `.ico` 格式，因此打包前需先用 `scripts/generate_app_icon.py`（需要 Pillow）把 PNG 轉成 `assets/app_icon.ico`，再由打包腳本讀取

要換成自己的圖示：

1. 準備一張透明背景的 PNG 圖檔（建議至少 256×256，需含多種常見尺寸時效果較佳）
2. 覆蓋掉 `assets/tray_icon.png`
3. 重新產生執行檔圖示：`python scripts/generate_app_icon.py`
4. 重新打包（見下方「打包成執行檔」）才會套用到系統匣與 exe 圖示

專案內建的滑鼠圖示是用 `scripts/generate_tray_icon.py` 以程式畫出來的（不需美術素材），想調整造型可直接修改該腳本後重新執行：

```bash
python scripts/generate_tray_icon.py
python scripts/generate_app_icon.py
```

## 設定檔位置

設定以 JSON 格式儲存在系統標準設定目錄下：

- Windows：`%APPDATA%\CoKaTile HUD\settings.json`
- macOS：`~/Library/Application Support/CoKaTile HUD/settings.json`

設定檔損毀或欄位不完整時，程式會自動補回預設值，不會導致啟動失敗。

## 安裝

```bash
pip install -r requirements.txt
```

macOS 另需（強化點擊穿透/權限提示時使用）：

```bash
pip install -r requirements-macos.txt
```

## 執行

```bash
python main.py
```

程式啟動後會在系統匣顯示圖示，右鍵點擊即可操作（見上方「系統匣選單」）。

### macOS 權限

macOS 需要「輔助使用權限」才能監聽全域滑鼠/鍵盤事件。首次啟動若未授權，程式會嘗試開啟系統設定頁面，請至「隱私權與安全性 → 輔助使用」中允許本程式。開發時直接用終端機執行取得的授權，跟未來打包成 `.app` 後的授權是分開的，打包後需重新授權一次。

## 測試

```bash
pip install -r requirements-dev.txt
pytest
```

自動化測試涵蓋搖晃偵測、設定讀寫、點擊漣漪動畫計算、熱鍵偵測、聚光燈平滑跟隨演算法、按鍵 HUD 按住/連點/放開狀態機、放大鏡擷取範圍計算等純邏輯；覆蓋層與多螢幕行為需手動驗證。

## 打包成執行檔

程式名稱與版號統一定義在 `app/version.py`（`APP_NAME` / `APP_VERSION`），打包腳本與系統匣提示文字都從這裡讀取，之後要發新版只需改這一處。

Windows 上用 PyInstaller 打包成單一 exe（`CoKaTile HUD.spec` 已附在專案中，可重複建置）：

```bash
pip install -r requirements-build.txt
python scripts/generate_app_icon.py      # 依 assets/tray_icon.png 產生執行檔圖示
pyinstaller "CoKaTile HUD.spec"
```

建置完成後執行檔位於 `dist/CoKaTile HUD v1.2.0.exe`（檔名含版號，來自 `app/version.py`），雙擊即可執行，不需另外安裝 Python 或依賴套件。`--windowed` 已設定，執行時不會跳出主控台視窗。

macOS 上請改用 `pyinstaller --onefile --windowed --name "CoKaTile HUD" main.py` 另外產生 `.app`（尚未在 macOS 上實測打包流程）。
